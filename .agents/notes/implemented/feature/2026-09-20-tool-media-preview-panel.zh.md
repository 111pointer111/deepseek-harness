# Agent Note: 工具图片资源预览面板

Status: implemented

[English](2026-09-20-tool-media-preview-panel.md) | 中文

## Problem

工具结果可以持久化图片附件，但 Chat 只显示工具调用文字。用户无法从连接器结果进入图片预览或浏览器下载。

## Decision

Chat 检测最新一个包含图片的已完成工具结果，并为该调用打开现有可调整宽度的详情栏。详情入口声明 `conversation.details.media`，由 `ui-attachment` 使用共享的会话授权图片画廊填充，因此工具资源与消息及 Trajectory 图片复用同一缓存、加载、重试和灯箱行为。灯箱通过原生下载链接暴露已解析的 blob URL，并使用附件名作为下载文件名。

## Alternatives considered

**新增另一套抽屉和资源 store。** 现有详情栏已经支持向左展开、收起、调整宽度并跟随选中的工具调用；重复这些职责会产生相互竞争的面板状态。

**把连接器 URL 直接暴露给浏览器。** 这会绕过会话授权附件加载器，并把连接器认证问题泄漏到呈现层。

## Consequences

返回图片的连接器结果会打开可关闭的资源面板，并在不新增传输和缓存的情况下支持预览与下载。核心内容类型目前仍只表示光栅图片附件；音频、视频与任意文件需要独立的持久附件契约后才能使用该表面。
